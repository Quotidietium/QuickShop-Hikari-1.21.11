## 二、完好不变式抽样（本轮验证为正确，不动）

- **SQL 全参数化**：26 处手写 SQL 构造点 + 80+ EasySQL builder 调用点逐条核对，用户可控值（玩家名/商店名/货币/标签/世界名/UUID）全部经 `addCondition/setParams/setColumnValues` 或 PreparedStatement 绑定；全仓 0 处 SQL LIKE（搜索为内存扫描）；ORDER BY 列名硬编码；批量 IN 两处均 `?` 占位+setLong；自写 SQL escape 函数不存在（无需关心 NO_BACKSLASH_ESCAPES）；输入治理最好的两条路径：店名限长 32、标签 normalizeTag 白名单正则+限长+参数绑定。
- **买家交物验证**：`removeItem` 先匹配后扣减、全仓调用方向一致；预检计数与扣减同源；不足熔断 + WriteTimeJournal 槽位级回滚 + 钱腿失败同 tick 反向搬运，无先扣后验。
- **默认匹配维度（work-type 1 = isSimilar）**：1.21 data component 全量精确比较（材质/耐久/附魔/书/CMD/容器内容/药水/旗帜/头颅/bundle/地图/纹饰等 20+ 维度逐项核对），数量正确忽略。
- **交易并发（GUI 拿取 vs 交易扣减）**：两者均主线程串行 + failSafeCommit 回滚 + null 容器 fail-closed，无复制/亏空窗口。
- **展示物**：仅剩 VIRTUALITEM（packet 假实体），无可拾取真实物；guard 物品由 DisplayProtectionListener+ChunkListener+inventoryCheck 三层兜底。
- **网络出口边界**：更新检查/遥测/bStats 确认不存在（R37 裁剪彻底）；playerdb.co 默认关；paste 为管理员手动+异步+PrivacyController 审查。
- **木牌解析面不存在**：本版木牌纯输出，无牌面文本→商店参数解析通道；价格输入 `Util.parse` 限长+SimplePriceLimiter NaN/负数/上限全拦截。
- **爆炸/活塞/实体/结构生长/方块破坏双保险/SignChange/开盖锁**：均确认有监听且有正确鉴权。

## 三、亲验修正（代理原报不成立）

1. `CalculateUtil.multiply(double,double)` 精度损失：实现为 BigDecimal 乘后转 double——两操作数单次乘法与 IEEE double 乘同为一舍入，经济 API 本身收 double，非缺陷。
2. 「generateSummary 12 串行 RTT」（R59 已录）：本轮复查维持非缺陷结论。
3. SnapshotGate 测试的 Shop mock 失败：根因是我测试代码在未完成 stubbing 中创建 mock（UnfinishedStubbingException），非 Shop 不可 mock。

## 四、已接受残留（带理由）

| # | 残留 | 理由 |
|---|---|---|
| 1 | SignUpdateWatcher 「先到 locale 赢」：并发交易同一商店时全局牌语言随机停留先调度者 | per-player 包路径（SignHooker）已保证各玩家本地化；全局方块文本语义本就是「某一默认视角」；允许覆盖 pending 条目会破坏去重契约，收益纯外观 |
| 2 | QuickShopItemMatcherImpl shulker 内含物按槽位严格对齐（work-type 0）：同物不同槽被判不匹配 | work-type 0 为遗留路径（默认 1），isSimilar 对 CONTAINER 组件整体相等无此问题；多重集回退改动大且语义有争议 |
| 3 | ModernCustomMatcher（work-type 3，opt-in）白名单外组件不比较（含 custom_data） | opt-in 宽松匹配器的设计选择；已在类注释与配置注释中声明语义；fail-closed 改动会破坏其存在意义 |
| 4 | JDBC URL 由配置裸拼（host/port/database 无字符校验） | 纯管理员面，错配置本就连不上库；URLEncoder 会改变合法值语义 |
| 5 | 漏斗放置守卫 `isOtherShopWithinHopperReach` 只匹配「朝下放在商店正下方」 | 实际转移已被本轮注入/抽取取消兜住（放置只是提醒性质）；facing 解析改动牵扯 PDC 语义 |
| 6 | owner-exclude 的漏斗授权仅在 owner-exclude=true 时生效，且只按创建者一人 | 既有产品语义；扩展到多人授权属新功能 |
| 7 | Folia region 一致性系统性方案、多服务器共享 DB 竞争、实机 E2E/浸泡 | R54–R59 连续留白维持（见 note/13 残留#6） |
| 8 | matcherplus 模块本地无法解析 | R37 起环境既有问题留档 |
